# Лабораторная работа № 8 — автоматические тесты библиотеки

Проект `primelist_tests` использует Qt Test и линкуется с той же статической библиотекой `primelist_lib`, которую используют оба приложения.

## Запуск в Qt Creator

1. Откройте `primelist_qt.pro` и выберите комплект **Desktop Qt MinGW**.
2. Выберите конфигурацию **Выпуск** и соберите проект. Используйте пути без кириллицы, например `8-src` и `build-lab8-release`.
3. Выберите конфигурацию запуска **primelist_tests** и запустите её без аргументов. Результаты появятся в выводе приложения. Тесты можно также запускать через панель **Результаты тестирования**.

Исполняемый файл на Windows находится в подкаталоге `primelist_tests/release/primelist_tests.exe` каталога сборки. При запуске из Qt Creator IDE добавляет нужные каталоги Qt и MinGW в PATH.

## Что проверяется

- Точный список простых чисел, исключение единицы и пустой результат для диапазона без простых чисел.
- Отдельное включение простой нижней и простой верхней границы. Дополнительно проверяется корректность обхода на верхнем пределе `int`.
- Для каждой границы проверяются ноль, отрицательное значение и превышение `INT_MAX`. Равные и обратные границы также отклоняются. Для всех восьми сценариев проверяются тип `std::out_of_range` и полный текст ошибки.
- Вычисление списка всех пятизначных простых чисел занимает не более 100 мс. Время измеряется только вокруг вызова библиотеки. После измерения результат сравнивается с независимым эталоном, построенным решетом Эратосфена.

Успешный запуск показывает `15 passed, 0 failed`. Строка `Five-digit prime list took … ms` показывает измеренное время на текущем компьютере.
