# Лабораторная работа № 10 — интернационализация

Графическое приложение `primelist_gui` поддерживает русский (`ru_RU`) и английский (`en_US`). При запуске оно выбирает первый поддерживаемый язык из списка языков интерфейса ОС. Если подходящего языка нет, используется английский.

Переводы заголовка, подписей, кнопок и диалогов ошибок хранятся в `primelist_gui/primelist_gui_ru_RU.ts` и `primelist_gui/primelist_gui_en_US.ts`. qmake запускает `lrelease` и встраивает готовые каталоги `.qm` в исполняемый файл как ресурсы `:/i18n`. Для редактирования переводов используйте Qt Linguist.

## Сборка и запуск в Qt Creator

1. Откройте `primelist_qt.pro` и соберите проект комплектом **Desktop Qt MinGW**. Для исходников и сборки используйте пути без кириллицы, например `10-src` и `build-lab10-release`.
2. Запустите **primelist_gui**. Проверьте заголовок окна, подписи полей и кнопку расчёта. Введите одинаковые границы, чтобы увидеть локализованный диалог ошибки.
3. Для ручной проверки второго языка поменяйте язык интерфейса ОС и запустите приложение снова. В Windows смена языка интерфейса может потребовать выхода из учётной записи.

## Автоматическая проверка

Запустите **primelist_gui_tests** без аргументов. Ожидаемый итог — `26 passed, 0 failed`. Тесты загружают оба встроенных каталога, проверяют подписи и сообщения об ошибках, а также английский язык при неподдерживаемой локали. Для проверки библиотеки отдельно запустите **primelist_tests**.

Поддержка локализации и заполнение каталогов сделаны отдельными коммитами в ветке `i18n`. Результат слияния находится в ветке `main`.
