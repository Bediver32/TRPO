# Лабораторная работа № 9 — автотесты графического интерфейса

Проект `primelist_gui_tests` на Qt Test использует ту же форму `Dialog` и ту же статическую библиотеку, что и графическое приложение. Тесты создают отдельный экземпляр формы для каждого сценария.

## Запуск в Qt Creator

1. Откройте `primelist_qt.pro`, выберите **Desktop Qt MinGW** и соберите проект. Используйте пути без кириллицы, например `9-src` и `build-lab9-release`.
2. В меню выбора цели запуска выберите **primelist_gui_tests** и нажмите **Ctrl+R**. Аргументы оставьте пустыми.
3. В выводе приложения ожидается `23 passed, 0 failed`. Тестовые диалоги ошибок закрываются автоматически. Для прогона тестов библиотеки из ЛР8 выберите `primelist_tests`.

## Сценарии

- Ввод с клавиатуры в каждое поле и сигнал кнопки, подключённый к обработчику `calculate()`.
- Цикл Tab. Нижняя граница → верхняя граница → «Вычислить» → список → нижняя граница.
- Полный сценарий ввода и вычисления. Для диапазона от 1 до 10 список содержит 2, 3, 5 и 7.
- Последовательные вычисления с разными диапазонами. Второй список заменяет первый.
- 14 сценариев ошибочного ввода. Проверяются появление одного диалога, заголовок, полный текст сообщения, тип значка и отсутствие результатов.

Создание проекта, модульные и интеграционные тесты зафиксированы отдельными коммитами.
